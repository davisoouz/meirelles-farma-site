# Meirelles Farma - site institucional

![Meirelles Farma](./image/mf/hero-img.png)

Site institucional da [Meirelles Farma](https://meirellesfarma.com.br/) que eu montei na época de **estágio**.

Landing com seções de sobre, missão/visão, e-commerce, eventos, contato e SAC.

## Stack

- HTML
- CSS (`meirelles.css`)
- Bootstrap 5
- jQuery + Slick Carousel (carrossel de parceiros)
- Font Awesome / Bootstrap Icons

## Como ver local

Abre o `index.html` no navegador, ou sobe um serverzinho:

```bash
npx serve .
```

## Observação

Projeto feito como estagiário para a Meirelles Farma.  
O site oficial continua em produção: https://meirellesfarma.com.br/
